# linux-notes

My Linux command line notes from my first semester at TUKE.
I write down commands as I learn them and explain each one in my own words.

## 📁 Moving around
| Command | What it does |
|---|---|
| `ls` | Shows what is inside the current folder |
| `cd folder_name` | Goes into a folder |
| `cd ..` | Goes back one folder (to the parent folder) |
| `mkdir folder_name` | Creates a new folder |

## ⚙️ Compiling and running C programs
| Command | What it does |
|---|---|
| `make name` | Compiles the program using the Makefile in the folder |
| `./name` | Runs the compiled program |
| `make name && ./name` | Compiles and runs it right away (runs only if compiling worked) |

## 🤖 Working with Karel (school library)
- The `.c` file, the map `.kw` and the `Makefile` must be in the same folder.
- Then I compile and run it with `make name && ./name`.

## 🌿 Git basics
| Command | What it does |
|---|---|
| `git --version` | Shows which version of git is installed |
| `git clone link` | Downloads a repository from GitHub to my computer |
| `git status` | Shows what I changed |
| `git add file` | Prepares a file to be saved |
| `git commit -m "message"` | Saves the changes with a short description |
| `git push` | Uploads my saved changes to GitHub |
